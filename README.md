# 🚀 My HTML 5 Million Prompters Program

## 📌 Loyihaning maqsadi

**My HTML 5 Million Prompters Program** — bu foydalanuvchilarga HTML asosida ishlovchi sahifalar yaratish, sun’iy intellekt (AI) yordamida promptlar yozish va zamonaviy web interfeyslar bilan ishlash imkonini beruvchi loyiha.

Ushbu loyiha orqali:

* HTML bilimlarini mustahkamlash
* AI prompt yozishni o‘rganish
* Web dizayn va frontend ko‘nikmalarni rivojlantirish mumkin

---

## 🛠 Texnologiyalar

Loyiha quyidagi texnologiyalar asosida yaratilgan:

* HTML5
* CSS3

---

## ⚙️ Asosiy funksiyalar

* 🧠 HTML sahifalar yaratish va preview qilish
* 🎨 Oddiy va tushunarli UI dizayn
